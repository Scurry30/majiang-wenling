# majiang-wenling

温岭麻将规则引擎。与 [majiang-core](https://github.com/kobalab/majiang-core) 平级，
不共用代码：温岭在牌组、手牌张数、和牌型、计分方式上都和日麻不同。

## 规则要点

| 项 | 值 |
|:--|:--|
| 牌张 | 144 张：万筒条 1-9 各 4 张 + 东南西北白发中 各 4 张 + 花牌 8 张 |
| 手牌 | 16 张制，庄家 17 张；和牌型 5 组面子 + 1 对将 |
| 财神 | 翻出的牌取出作指示，同种剩 3 张为万能牌（最多 3 张） |
| 计分 | 分数 = 胡头 × 2^台数；闲家另按基础胡头两两差额结算 |
| 腊子 | 3 张财神 / 四红花 / 四黑花 / 四风齐，封顶 500 |
| 流局 | 剩 8 墩（16 张）无人胡牌 |
| 七对 | 不存在 |

完整规格见主工程 `Majiang/docs/rulesets.md`。

## 实现约定（规则原文没写死、按下面处理）

| 项 | 处理 |
|:--|:--|
| 吃牌 | 只能吃**上家**打出的牌（即打牌者的下家吃），默认按这个理解 |
| 流局 | 牌墙 ≤ 16 张（8 墩）时判流局 |
| 连庄 | 胡牌连庄；流局下庄 |
| 杠上开花 | 明杠 / 暗杠 / 加杠后补牌即和，+1 台 |
| 抢杠 | 只在**加杠**时可抢；暗杠不可抢 |
| 财神 | 不能用于吃碰杠；拼凑出的面子不计胡头 |
