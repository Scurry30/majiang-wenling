# majiang-wenling

温岭麻将规则引擎。与 [majiang-core](https://github.com/kobalab/majiang-core) 平级，
不共用代码：温岭在牌组、手牌张数、和牌型、计分方式上都和日麻不同。

## 规则要点

| 项 | 值 |
|:--|:--|
| 牌张 | 144 张：万筒条 1-9 各 4 张 + 东南西北白发中 各 4 张 + 花牌 8 张 |
| 手牌 | 16 张制，庄家 17 张；和牌型 5 组面子 + 1 对将 |
| 财神 | 翻出的牌取出作指示，同种剩 3 张为万能牌（最多 3 张） |
| 计分 | 分数 = 胡头 × 2^台数；闲家另按基础胡头两两差额结算 |
| 腊子 | 3 张财神 / 四红花（春夏秋冬）/ 四黑花（梅兰竹菊）/ 四风齐，封顶 500 |
| 流局 | 剩 8 墩（16 张）无人胡牌 |
| 七对 | 不存在 |

完整规格见主工程 `Majiang/docs/rulesets.md`。

## 牌谱

一局牌谱 = **开牌种子 + 每一步决策**（约 2-5 KB），不存逐帧快照。
回放时用同一个种子重跑引擎、按顺序喂回决策，过程与当时完全一致；
每条决策带签名，引擎改动导致错位会直接报错，不会静默出错。

- 记录：`record_game(rule, policy, {seed})` → `{record, result, game}`
- 回放：`replay_game(record)` → `{states, log, result}`，`states` 可逐手渲染
- 界面：对局结算面板「回放这局」；历史在导航「温岭牌谱」（localStorage，最多 30 局）

## AI

评估函数（`lib/ai.js`）：

```
分数 = -向听 × 1000 + 有效牌 / 等牌价值
```

- **有效牌扣除已见牌**：四家牌河 + 所有副露算进「还剩几张」，A/B 80 局比不扣多 10 个胜局
- **听牌时比等牌价值**：`等牌张数 × 2^台数潜力`，同样是 80 局多 12 个胜局
- 台数潜力（一色 / 对对 / 闹闹 / 门风 / 腊子）**只在听牌阶段**参与，早期参与会把牌型带偏（实测 2v2 会从 42 胜掉到 18 胜）
- 鸣牌：吃/碰只在真的降向听时才做；杠一律不做

`ai.analyze(hand, ctx)` 是给界面用的牌效分析：当前向听、每个候选打法的向听/有效牌、
听牌时的等牌与剩余张数。对局页右侧「牌效提示」面板就用它（可在页面里关闭）。

## 实现约定（规则原文没写死、按下面处理）

| 项 | 处理 |
|:--|:--|
| 吃牌 | 只能吃**上家**打出的牌（即打牌者的下家吃） |
| 食替 | 吃牌后不能立刻打出刚吃进的那张（`rule['食替限制']`，可关） |
| 流局 | 牌墙 ≤ 16 张（8 墩）时判流局 |
| 连庄 | 胡牌连庄，本场 +1；闲家和牌或流局 → 庄家轮转、局数 +1、本场清零 |
| 杠上开花 | 明杠 / 暗杠 / 加杠后补牌即和，+1 台 |
| 抢杠 | 只在**加杠**时可抢；暗杠不可抢 |
| 财神 | 不能用于吃碰杠；拼凑出的面子不计胡头 |
| 财神归位 | 手里的财神当它本来的牌种就能和成 → +1 台 |
| 腊子的花 | 只看**胡牌这一家自己收集**的花牌：同一家同时拥有 4 张四季花或 4 张四君子才算 |
